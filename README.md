# CarbonTrack

Industrial energy and carbon management SaaS platform. This repository is being initialized for the CarbonTrack MVP.

## Planned stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS, Recharts
- Backend: FastAPI, SQLAlchemy, PostgreSQL, Alembic
- Deployment: Docker Compose

The MVP will prioritize organization and factory management, consumption tracking, transparent emissions calculations using sourced/configurable emission factors, and dashboard analytics. No emission factors will be invented or silently assumed.
